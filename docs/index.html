Axiom

個人化 AI 學習 Agent 的實際開發過程與專案歷程。 Axiom 不是 chatbot wrapper——Model 只是 Brain；產品是 Student Model、Context、Policy 與 Learning Loop。

產品初衷 開發時間線 技術棧 驗證紀錄 原始碼與文件

產品初衷（不變的邊界）

開發全程以這組原則約束，避免變成「選模型聊天」。Learning Loop / Mastery / Error DNA / AQE 的寫入路徑刻意不重寫。

Axiom ≠ Chatbot Student Model + Memory + Context + Policy + Agent + Learning Loop
Model = Brain Ollama / OpenAI / Gemini 可替換；不取代「理解學習者」的責任
閉環 Observe → Understand → Adapt → Teach → Outcome → 再理解
證據優先 不夠資料就說「尚無足夠資料」，不捏造個人化
